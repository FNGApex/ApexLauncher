# Project signals

## Framework & runtime

- **Frontend:** React 19, TypeScript ~5.8, Vite 7, Tailwind v4, React Router v7, TanStack Query v5, Zustand v5
- **Backend:** Rust 1.96, Tauri 2 (protocol-asset feature); reqwest (rustls-tls, default-features=false; json+stream+charset+http2+macos-system-configuration)
- **Key Rust deps:** serde/serde_json, uuid, chrono, sha1/sha2/hex, md-5, futures-util, tokio (sync+rt+process+time+macros), flate2, tar, zip, keyring 3 (apple-native+windows-native+sync-secret-service), async-trait, thiserror, tempfile (dev), notify="=8.2.0" + notify-debouncer-full="=0.7.0" (pinned; mods-dir watch)
- **Targets:** macOS, Windows, Linux
- **Branding:** product `ApexLauncher`; bundle id `com.apex.apexlauncher`; Cargo crate `modloader` / `modloader_lib`
- **App version:** 0.1.0 pre-alpha; Phases 0–6 complete
- **IPC type generation:** `src/lib/bindings.ts` generated by tauri-specta at dev startup; committed; single source of truth for all commands, events, and DTOs. Regenerate via `scripts/build.sh dev` on Windows (wait for `[bindings] exported`). `src/lib/ipc.ts` is a thin adapter over `bindings.ts`.
- **CF API key:** resolves env (`MODLOADER_CF_API_KEY`) → `settings.curseforge_api_key` → baked (`build.rs` reads gitignored `src-tauri/.env`). Never committed.

## Build / test / lint

| Purpose | Command | Source |
|---------|---------|--------|
| Typecheck (cargo check + tsc) | `scripts/build.sh check` | scripts/build.sh |
| Rust tests (+ filter) | `scripts/build.sh test [filter]` | scripts/build.sh |
| Real app bundle | `scripts/build.sh build` | scripts/build.sh |
| Dev window (HMR) | `scripts/build.sh dev` | scripts/build.sh |

**Always use `scripts/build.sh`.** On WSL: mirrors source to native Windows FS then builds via `scripts/apex-build.bat`. On macOS/Linux: builds natively in place. Do not call `cargo`/`npm` directly.

**CI** (`test.yml` + `bundle.yml`): calls cargo/npm/tauri directly on native runners — the one sanctioned exception. `test.yml`: ubuntu rust-test (nextest --retries 2) + frontend tsc/vite + bindings-drift gate on PRs; full 3-OS on push-to-main. `bundle.yml`: all installers (MSI/NSIS/DMG×2/AppImage/tarball) on `v*` tags + dispatch. Spec: `docs/spec/ci-pipeline.md`.

**Known test flake:** `cp4_concurrency_bound_not_exceeded` in `download_tests.rs` — timing-sensitive; CI absorbs via `--retries 2`.

## Cross-cutting

- **Task-queue contract:** `add_mod`, `update_mod`, `import_mrpack`, `import_curseforge_zip`, `install_modpack` (all providers), `update_modpack`, `import_external_instance` return `u64` task id. Results arrive via `task://update` when `status.kind === "done"` and `task.result` is set. `set_mod_enabled`, `remove_mod`, `set_pack_lock`, `set_instance_java`, `set_pending_launch_warning_suppressed`, `set_instance_icon`, `clear_instance_icon` are synchronous. `enrich_instance_mods` is async but not task-queued. `rescan_pending_manual`, `import_manual_file`, `start_pending_watch`, `stop_pending_watch` are synchronous. `update_modpack` for FTB/ATL returns an error string immediately (update-apply deferred to v2).
- **Zustand stores:** `useAppStore` (tasks `Map<number,Task>`, runs `Map<string,RunState>`, runLogs `Map<string,RunLogLine[]>`); `useUiStore` (sidebarCollapsed, browseProvider `"curseforge"|"modrinth"|"ftb"|"atlauncher"`). `AppShell` is sole event-driven subscriber; routes read from store.
- **Event channels:** `task://progress`, `task://update`, `run://update`, `launch://log`, `launch://exit`, `install://log`, `download://progress`, `auth://device-code`, `manual://resolved`, `crash://analyzed` (`CrashAnalyzedPayload { slug, analysis }` — post-exit crash analysis from `core/crash.rs` + `detect_crash` hook in `core/launch.rs`; `get_crash_analysis` sync command backfills; AppShell clears on relaunch) (`ManualResolvedPayload { slug, resolved: Vec<ResolvedManual>, remaining: u32 }` — emitted by PendingWatcher and by rescan/import after reconcile; AppShell invalidates `["instance", slug]`).
- **`ProviderKind` string shapes:** serde `"curseForge"` (camelCase) vs ipc.ts routing `"curseforge"` (lowercase) are distinct. `"ftb"` and `"atlauncher"` are the same in both forms.
- **Test layout:** Unit tests in sibling `<stem>_tests.rs`. Each source module ends `#[cfg(test)] #[path = "<stem>_tests.rs"] mod tests;`. Module-scope `#[cfg(test)]` scaffolding stays in the source file. Total: **911** lib tests (44 download + 43 resolver + 43 java + 11 java_resolve + 54 launch + 40 auth + 20 loader_profile + 52 instances + 13 store + 9 materialize + 14 forge_installer + 41 mod_install + 35 providers + 72 curseforge + 41 modrinth + 113 modpack + 59 lib_tests + 17 task_manager + 15 settings + 11 ftb + 18 atl + 82 launcher_import + 62 crash) + 10 integration tests in `src-tauri/tests/` (+ `tls_live.rs` `#[ignore]` excluded).
- **App data dir:** `<OS-appdata-base>/ApexLauncher/`. macOS: `~/Library/Application Support/ApexLauncher/`. Windows: `%APPDATA%\ApexLauncher\`. Linux: `~/.local/share/ApexLauncher/`. Cache: `cache/{assets,libraries,versions,java,meta,installers}`.
- **Staging/promote pattern:** `remap_to_staging` + `promote_staging` (defined in `core/modpack.rs`) shared by all 8 job types. Staging dir: `<inst_dir>/.staging-<task_id>/`. Cancel/fail: `remove_dir_all(staging_dir)`.
- **Per-instance Java/RAM:** `JavaCfg` (`major`, `args_override`, `memory_mb`, `min_memory_mb`, `path_override`, `use_pack_settings`). `resolve_effective_java(inst, settings)` → `EffectiveJava`: 3-tier: (1) `inst.source.recommended` (pack-recommended; populated for FTB from `specs.recommended`, ATL from `manifest.memory > 0`), (2) per-instance when `use_pack_settings == true`, (3) global settings.
- **Mod metadata:** `ModEntry` carries `name/icon_url/summary: Option<String>` with `#[serde(default)]`. Captured at add-time. `enrich_instance_mods` backfills mods with all-None metadata via batched `get_projects_brief`.
- **Pack update-check:** `Source` carries `last_update_check`, `latest_version`, `latest_version_id`. `refresh_pack_meta` throttled to 24h. FTB/ATL update-apply deferred to v2; update-check still works.
- **Settings fields:** `default_memory_mb`, `default_java_args`, `curseforge_api_key`, `offline_mode`, `sidebar_start_collapsed`, `auto_download_java`, `show_console_default`, `keep_launcher_open`, `maximize_on_start`.
- **Materialize:** `core/materialize.rs` — hardlink+copy-fallback; `launch_instance` calls `rewrite_classpath_for_instance` + `materialize` at step 6b.
- **Deterministic substrate:** `.claude/project/deterministic-signals.md`
